# ESG-Report-Intelligence-System

7-Day	Execution	Plan
Goal:	Ship	a	working,	deployed,	interview-ready	RAG	project	in	7
days.	Assumption:	You	already	know	Python	and	core	ML.	This	plan
skips	theory-heavy	learning	and	focuses	on	implementation.	Where
deeper	concepts	exist	in	the	full	guide,	they	are	marked	[Learn
Later].
How	to	Use	This	Plan
Each	day	has	a	strict	time	budget.	Do	not	exceed	it	—	momentum
matters	more	than	perfection.
Commit	to	Git	at	every	checkpoint,	not	just	at	end	of	day.	If
something	breaks,	you	can	roll	back.
If	you	fall	behind	by	more	than	3	hours	on	any	day,	switch
immediately	to	the	Minimum	Viable	Version	track	(Section:	MVP
in	4	Days)	instead	of	trying	to	catch	up	on	the	full	plan.
